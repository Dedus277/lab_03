# ЛР3. Каталог транспортных маршрутов

Это маленькая программа на Python, которая хранит транспортные маршруты: автобусы, трамваи, метро и так далее. Маршруты можно добавлять, искать, удалять, а ещё сохранять в файл и потом загружать обратно.

Мне достался вариант «транспортные маршруты».

## Как всё устроено

Проект делится на четыре файла, и у каждого своя задача:

- `model.py`: описывает один маршрут (класс `Route`);
- `catalog.py`: хранит много маршрутов и умеет с ними работать (класс `Catalog`);
- `storage.py`: записывает каталог в файл и читает его обратно;
- `exceptions.py`: ошибки, которые программа выдаёт, когда что-то идёт не так.

Тесты лежат в папке `tests`.

## Что такое маршрут

У каждого маршрута есть шесть данных:

- `id`: уникальный код, например `bus-12`;
- `name`: название, например «Вокзал — Университет»;
- `category`: вид транспорта: `bus`, `train`, `trolleybus` или `metro`;
- `year`: год открытия, от 1800 до текущего;
- `length_km`: длина в километрах, должна быть больше 0;
- `stop_count`: число остановок, целое, не меньше 2.

Всё это проверяется в момент создания. Если, например, написать год 2999 или оставить название пустым, маршрут не создастся и программа сообщит об ошибке. Так в каталог не может попасть неправильный маршрут.

После создания маршрут менять нельзя. Это сделано специально: если бы кто-то поменял `id` у маршрута, который уже лежит в каталоге, каталог запутался бы.

## Что умеет каталог

- `add(route)`: положить маршрут. Если маршрут с таким `id` уже есть, будет ошибка, и ничего не изменится.
- `get(id)`: достать маршрут по `id`. Если такого нет, будет ошибка.
- `remove(id)`: удалить маршрут. Если такого нет, тоже ошибка.
- `find_by_category(category)`: найти все маршруты одного вида транспорта.
- `find_by_name(text)`: найти все маршруты, в названии которых есть этот текст. Большие и маленькие буквы не важны.
- `len(catalog)`: сколько всего маршрутов.
- `id in catalog`: есть ли маршрут с таким `id`.
- `for route in catalog`: пройтись по всем маршрутам.

Маршруты всегда идут в том порядке, в котором их добавляли. Сколько раз ни перебирай, порядок будет один и тот же.

### Быстро или медленно

Внутри каталог хранит словарь, где ключ это `id`, а значение это сам маршрут. Поэтому `get`, `add`, `remove` и `in` работают мгновенно: программа сразу идёт к нужной записи, не просматривая остальные. Это называется O(1): время не зависит от того, сколько в каталоге маршрутов.

А вот `find_by_name` и `find_by_category` приходится проверять каждый маршрут по очереди. Это называется O(n): чем больше маршрутов, тем дольше поиск.

### Защита от случайной порчи

- Поиск возвращает новый список. Если его изменить или очистить, каталог не пострадает.
- Если во время перебора каталога удалять из него маршруты, ничего не сломается, потому что перебор идёт по копии.

## Какие бывают ошибки

Все ошибки наследуются от `CatalogError`, поэтому одним `except CatalogError` можно поймать любую:

- `InvalidEntityError`: маршрут не прошёл проверку при создании;
- `DuplicateIDError`: такой `id` уже занят;
- `ItemNotFoundError`: маршрута с таким `id` нет;
- `UnsupportedVersionError`: файл записан в неизвестной версии формата;
- `CorruptedFileError`: файл повреждён или записан неправильно.

## Сохранение в файл

Каталог записывается в JSON-файл, который выглядит так:

```json
{
  "format_version": 1,
  "items": [
    {
      "id": "bus-12",
      "name": "Вокзал — Университет",
      "category": "bus",
      "year": 1990,
      "length_km": 12.5,
      "stop_count": 15
    }
  ]
}
```

`format_version` показывает, в каком формате записан файл. Если версия незнакомая, загрузка откажется читать такой файл.

Как этим пользоваться:

```python
from catalog_pkg.catalog import Catalog
from catalog_pkg.storage import save, load

save(catalog, "routes.json")      # записать каталог в файл

new_catalog = Catalog()
load(new_catalog, "routes.json")  # прочитать файл в каталог
```

### Что если файл испорчен

Загрузка сделана так, чтобы плохой файл ничего не сломал:

1. Сначала файл полностью читается и проверяется: что это правильный JSON, что версия известна, что каждая запись корректна.
2. Все маршруты складываются во временный каталог.
3. Только если всё прошло без ошибок, содержимое настоящего каталога заменяется на загруженное.

Поэтому, даже если ошибка спрятана в самой последней записи файла, каталог останется точно таким, каким был до загрузки.

## Как запустить тесты

Из папки `lab_03`:

```
python -m unittest -v
```

Тесты проверяют, что:

- правильные маршруты создаются, а неправильные отклоняются;
- добавление, получение и удаление работают, а дубликаты и несуществующие `id` дают ошибки;
- поиск находит нужное, в том числе при разном регистре;
- порядок перебора не меняется;
- каталог после сохранения и загрузки остаётся тем же;
- битый файл и неизвестная версия отклоняются;
- после неудачной загрузки каталог не меняется.
